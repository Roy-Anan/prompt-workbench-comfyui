# MODEL PROFILE TEMPLATE
# 绘图模型专属提示词规则模板

说明：

本文件用于创建模型专属 Prompt Profile。

模型 Profile 的核心任务不是介绍模型，而是指导提示词助手如何针对这个模型组织、表达和优化 Prompt。

填写时必须区分：
- 已验证事实：有模型作者资料、模型卡、实际测试等依据。
- 高可信经验：有较多实际使用经验，但不属于官方明确规定。
- 未确认信息：来源不足、存在争议或尚未测试。

不要将猜测写成模型的确定特性。
